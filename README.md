# fuzzy-linear-regression-for-crop-yield

This repository contains the codes used in the study titled
“Fuzzy Linear Regression versus Machine Learning Algorithms for
Crop-Specific Yield Prediction.”

The `GEE_data` folder contains the Google Earth Engine JavaScript codes
used to obtain the environmental variables for Türkiye for 2000–2024.

Crop yield data were obtained from FAOSTAT:

https://www.fao.org/faostat/

The R codes used in the analysis are provided in the `R_analysis` folder.
